↻ 버튼으로 바로 수집하기

GitHub 토큰을 한 번 넣어 두면, ↻를 누를 때 공시 수집과 AI 요약이 바로 실행되고 끝나면 화면이 자동으로 바뀌어요. 토큰은 이 기기의 브라우저에만 저장되고 사이트 코드나 저장소에는 올라가지 않아요.

  1. GitHub → 프로필 사진 → Settings → Developer settings
  2. Personal access tokens → Fine-grained tokens → Generate new token
  3. Repository access: Only select repositories → gongsi-radar
  4. Permissions → Actions와 Contents를 각각 Read and write로 → Generate token (Contents는 관심종목을 기기 간에 저장할 때 써요)
